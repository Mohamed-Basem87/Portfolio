# Mohamed Basem Portfolio

A modern and responsive personal portfolio website built to showcase my projects, skills, certifications, and experience in Data Analysis, Business Intelligence, and Artificial Intelligence.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Interactive project showcase
* Skills and technologies section
* Education and certifications
* Professional experience
* Contact information and social links
* Fast and modern React-based interface

## Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3 / SCSS
* Git & GitHub

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js (v18 or later recommended)
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Mohamed-Basem87/portfolio.git
```

Navigate to the project folder:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```

## Build for Production

Create an optimized production build:

```bash
npm run build
```

## Customization

Most portfolio content can be modified from:

```text
src/portfolio.js
```

You can update:

* Personal information
* Skills
* Education
* Projects
* Certifications
* Contact information
* Social media links

Theme colors can be customized through:

```text
src/_globalColor.scss
```
